# Decoline

The official portfolio and enquiry website for Decoline—original handcrafted metal art by Rajesh Khadse in Nagpur, India.

## Local development

```bash
npm install
npm run dev
```

## Production

The repository supports both the bundled Sites build (`npm run build`) and a native Next.js build for Vercel (`npx next build`).
